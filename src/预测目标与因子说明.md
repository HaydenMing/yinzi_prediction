# 给导师说明：输入是什么，输出是什么

## 因子是什么
因子是从已有新闻中提取的一条文字记录，核心字段为：
- name：具体因素名称。
- explanation：依据新闻说明它与目标物料价格可能存在的联系。
- evidence：可回到新闻核对的原句和位置。
- unit_id、published_at、source_url：新闻来源。

例如“计划扩产”可描述供给或需求的变化，但“计划”不能写成“已经发生”。影响方向和路径可以是解释中的假设，不能伪称已经确认的因果结论。
目前没有统一标注的因子涨跌类别、强度分数、涨幅百分比或置信度。模型读取名称和解释形成向量。向量的某一维不是“上涨0.5%”，也不能把一条因素换算为确定涨价金额。
真实记录请看运行后的data/物料/因子输入目录.csv。不存在重新调用大模型补数值标签的步骤。

## 预测输出是什么
输入：截至预测截止点的20个报价日价格/价差，以及相应新闻、因子。
监督目标：下一个报价日价格相对上一报价的变化。
输出：一个连续价格数值；同时列出这个价格对应的价差、百分比及方向。
这里的“下一日”是下一个报价日，并不一定是下一个自然日。

设上一报价P_t，真实下一报价P_(t+1)。训练期价差尺度：
s = max(Std_train(P_(t+1) - P_t), 1)
训练标签：
z_(t+1) = (P_(t+1) - P_t) / s

三路独立编码后的表示为H_p、H_n、H_f；融合主体输出向量v：
v = Fusion_k(H_p, H_n, H_f)
框架①③④⑤最终用两层全连接回归：
z_hat = W2 · GELU(W1 · v + b1) + b2
③④⑤训练时还有Dropout，推理时关闭。
框架②的三个预测分支分别输出z_hat_j，再由softmax权重合并：
z_hat = Σ_j alpha_j · z_hat_j，alpha_j >= 0，Σ alpha_j = 1

恢复最终价格：
P_hat_(t+1) = P_t + s · z_hat
预测价差：
delta_hat = s · z_hat
预测变化百分比：
r_hat = 100 · delta_hat / P_t
预测方向：
delta_hat > 1e-8为上涨；小于-1e-8为下跌；其余持平。阈值是原价格尺度的浮点零容差，不是分类阈值。

数值例子（只为解释公式，不是某天真实结果）：
上一报价100，训练尺度20，模型输出0.5。
预测价差=10，预测价格=110，预测变化=10%，派生方向=上涨。
这里的“0.5”是整个模型的标准化价差预测，不是某条因子的方向或强度。

## 优化什么
主要预测损失：L_pred = mean((z_hat - z)^2)。
①另有分支预测、PN/PS代理监督、对比学习和高斯分布约束，保留旧代码系数。PN/PS不能宣称真实因果已被识别。
每个checkpoint按验证集原价格尺度MAE选择，再按三个种子平均验证MAE选择方案。测试不参与选择。

## 两种融合顺序的公式
late：
H_p = PriceEncoder(P)
H_n = NewsTemporal(NewsTextEncoder(news))
H_f = FactorTemporal(FactorTextEncoder(factor))
v = Fusion_k(H_p, H_n, H_f)

early：
E = concat_tokens(Linear(P), state_embedding, character_embedding(news), character_embedding(factor))
H = SharedTemporal(SharedFeatureEncoder(E))
[V1,V2,V3] = split(Linear(H))
v = Fusion_k(V1,V2,V3)
基础表示都含类型向量；长文字分块，每块带价格与状态前缀。V1/V2/V3都是混合视图，不再具有独立模态含义。

## 到哪里对照源码
- data.py / prepare_material：原新闻、因子、固定价格窗口及训练字表。
- model.py / MultimodalModel.forward：late三路特征变量；early联合编码入口。
- model.py / JointEncoder.forward：joint_tokens确实含价格、新闻、因子，先拼接再共享提取。
- encoders.py / CharacterEncoder：原文TextCNN、mean、BiGRU。
- encoders.py / TemporalEncoder：价格或跨报价日GRU/TCN。
- fusion.py / FusionBackbone.forward：五种融合、fusion_features、prediction。
- training.py / predict：取出prediction。
- common.py / prediction_rows：还原预测价格、价差、百分比、方向。
- training.py / evaluate_one：测试逐日报价预测.csv及features.npz。
